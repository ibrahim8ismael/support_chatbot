# How do I turn on two-factor authentication?

Open Settings → Security and choose "Two-factor authentication". Scan the QR code with an authenticator app such as Authy or Google Authenticator, then enter the 6-digit code to confirm. Save the backup codes — each backup code works once.

Lost your phone and cannot use two-factor authentication? Sign in with a backup code and re-enable two-factor authentication from Settings → Security.
